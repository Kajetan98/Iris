IRIS to program: host w Pythonie, który rozmawia przez model językowy, prowadzi własny stan i zapisuje fakty o Tobie. Rozmawiasz z nim przez przeglądarkę na telefonie, program na komputerze albo urządzenie HERMES.

Jak IRIS się uczy

Model językowy się nie zmienia. Uczy się program: zapisuje fakty w bazie i według stałych reguł decyduje, czym są i kiedy ich użyć. Poniżej przykład z testów, w którym odpowiedzi modelu zastąpiła atrapa.

  1. Ty Idę z Burkiem na spacer.

    Miłego spaceru.

    W tle model proponuje fakt: "Masz psa o imieniu Burek". Pewność 45%, więc IRIS jeszcze go nie używa w rozmowie.

  2. Ty Jaka będzie jutro pogoda?

    Jutro ma być słonecznie, około 18 stopni. Czy dobrze rozumiem: masz psa o imieniu Burek?

    Pytanie dopisuje host, nie model. Najwyżej jedno na 15 minut, żadnego w trybie ciszy.

  3. Ty Tak, zgadza się.

    Dobrze, zapamiętane.

    Odpowiedź obsługuje host, bez modelu. Fakt jest teraz pewny.

  4. Ty Zapamiętaj, że w piątki gram w kosza.

    Zapamiętane: "w piątki gram w kosza".

    Fakt podany wprost jest pewny od razu.

  5. Ty Co o mnie wiesz?

    Wiem od ciebie: "w piątki gram w kosza"; "masz psa o imieniu Burek".

    Ta sama lista jest w aplikacji pod przyciskiem z książką, gdzie każdy fakt można usunąć.

  • Mówisz wprost

    zapamiętaj, że ..., zapomnij ..., co o mnie wiesz, zapomnij wszystko (po potwierdzeniu). Obsługuje je host, także bez modelu.

  • Wyciąga przypuszczenia

    Po każdej odpowiedzi model w tle proponuje fakty z Twojej wypowiedzi. Nowe zaczyna od 45%, każde powtórzenie dodaje 20 punktów, do 90%. Od 50% trafia do rozmowy.

  • Pyta

    "Czy dobrze rozumiem: ...?" Odpowiedź "tak" robi z przypuszczenia pewny fakt, "nie" je usuwa, a "nie, mam kota" zapisuje poprawkę.

  • Zapomina

    Przypuszczenie, które przez 30 dni się nie powtórzy, traci 10 punktów, a poniżej 20% znika. Fakty podane wprost nie zanikają.

Czego IRIS nie robi sama

  • O zdrowiu, lekach, adresie, pieniądzach, wyznaniu, poglądach i orientacji nie wyciąga wniosków. Zapisze to tylko po poleceniu "zapamiętaj".
  • Przypuszczenia wyciąga domyślnie tylko lokalny model (Ollama). Do modelu trafia sama Twoja wypowiedź, bez historii i znanych faktów.
  • Treść faktów jest tylko w bazie. Nie ma jej w zapisie zdarzeń ani w logach.

Jedno aktywne urządzenie

Do hosta może być podłączonych kilka urządzeń, ale rozmawia jedno. Przełączasz je przyciskiem albo głosem: "przełącz na laptop".

  • Przeglądarka

    Telefon lub komputer. Klient działa pod adresem hosta i można go zainstalować jako aplikację. Wymaga HTTPS, a na komputerze z hostem wystarcza localhost.

  • Komputer i Raspberry Pi

    Program używający mikrofonu i głośnika systemu. Może słuchać bez rąk, po głośności.

  • HERMES

    Urządzenie z mikrofonem, głośnikiem i czujnikami (STM32L476). Prosty stan trzyma lokalnie, resztę host.

Instalacja

Host działa na Twoim komputerze lub Raspberry Pi. Na telefonie otwierasz jego adres HTTPS i instalujesz stronę jako aplikację.

Linux i macOS

git clone -b main https://github.com/Kajetan98/Iris.git iris && cd iris
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[voice]"
cp iris.example.toml iris.toml
IRIS_CONFIG=iris.toml uvicorn host.api.main:app

Windows (cmd)

git clone -b main https://github.com/Kajetan98/Iris.git iris
cd iris
python -m venv .venv
.venv\Scripts\activate.bat
pip install -e ".[voice]"
copy iris.example.toml iris.toml
set IRIS_CONFIG=iris.toml
uvicorn host.api.main:app
  1. Pobierz model w Ollamie (np. ollama pull llama3.1) i polski głos Pipera (pliki .onnx i .onnx.json) do katalogu voices/. Ścieżki ustawia iris.toml.
  2. Na komputerze otwórz http://localhost:8000/app/ w Chrome lub Edge.
  3. Na telefon wystaw hosta przez HTTPS, np. Tailscale Serve (tailscale serve --bg 8000) albo tunel Cloudflare. Przez tunel ustaw IRIS_TOKEN, bez niego host odrzuca takie połączenia.
  4. W iris.toml dodaj adres tej strony: [api] i cors_origins = ["https://iris-asystent.vercel.app"], a potem uruchom host ponownie.
  5. Na telefonie otwórz aplikację IRIS, w ustawieniach wpisz nazwę urządzenia, adres hosta (https) i token, a potem zainstaluj ją z menu przeglądarki ("Zainstaluj aplikację" albo "Do ekranu początkowego"). Adres aplikacji jest stały, zmienia się tylko adres hosta w ustawieniach.
