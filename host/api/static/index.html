Brak połączenia z hostem

Tu pojawi się zapis rozmowy. Zostaje tylko na tej stronie.

    Ta przeglądarka nie nagrywa ani nie odtwarza mowy (brak WebCodecs z Opus albo strona otwarta bez HTTPS). Użyj Chrome lub Edge przez HTTPS albo na localhost.

    Połączenie z hostem

    Małe litery, cyfry i myślnik, np. telefon albo laptop. Po tej nazwie przełączasz urządzenia.

    Ten sam co IRIS_TOKEN na hoście. Zostaw puste, jeśli host go nie wymaga.

    Napisy rozmowy zostają tylko na tej stronie i znikają po jej zamknięciu.
